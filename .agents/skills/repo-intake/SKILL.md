## Goal

Orient efficiently before work starts.

## Read first

1. `CLAUDE.md`
2. `plan.md`
3. `git status`
4. Only Markdown referenced by the current task

## Workflow

Identify the current task, search for relevant filenames/headings, read only governing contracts, then inspect relevant files.

## Constraints

Do not recursively read `docs/`, repeat reads without need, or implement anything.

## Output

Current task, relevant contracts/files, risks, and likely commands if known.
