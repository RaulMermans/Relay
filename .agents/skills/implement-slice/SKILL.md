## Goal

Deliver the smallest correct change for one task.

## Read first

`CLAUDE.md`, `plan.md`, the task contract, and only governing Markdown plus relevant code.

## Workflow

Inspect -> read relevant contracts -> make minimal implementation -> run targeted verification -> report result.

## Constraints

No speculative refactors, unrelated edits, or unjustified dependencies. Behavior changes require tests.

## Output

Changed files, acceptance-criteria result, verification evidence, and remaining risks.
