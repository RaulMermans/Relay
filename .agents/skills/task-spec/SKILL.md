name: task-spec
description: Use to turn one approved Relay task into an executable contract before implementation. Do not use for broad roadmap planning or to implement the task.
---

## Goal

Make one implementation unit unambiguous and testable.

## Read first

`CLAUDE.md`, `plan.md`, and only contracts that govern the task.

## Workflow

State the task ID, outcome, context, scope, exclusions, acceptance criteria, target files, relevant docs, verification, and rollback when relevant.

## Constraints

Specify one task only; avoid speculative architecture and unstated dependencies.

## Output

A concise executable task contract.
