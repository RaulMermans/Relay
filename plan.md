# Sprint 00 - Project Operating System

## Goal

Create Relay's project operating system from an empty folder.

## Non-goals

- No application scaffold or dependencies
- No product implementation
- No connectors
- No database

## Tasks

### T-001 Create repository structure

**Acceptance criteria:** requested root, `docs/`, `fixtures/`, and `.agents/skills/` paths exist; fixture folders are retained in Git; no product code is introduced.

### T-002 Create project operating Markdown

**Acceptance criteria:** every requested Markdown file contains a concise, useful starter contract; `CLAUDE.md` is compact; current plans stay in this file and the full roadmap stays in `docs/roadmap/SPRINTS.md`.

### T-003 Create initial skills

**Acceptance criteria:** each skill has trigger metadata, focused goal, read-first guidance, workflow, constraints, and output; skills use progressive disclosure and do not duplicate the operational contract.

### T-004 Create roadmap

**Acceptance criteria:** the roadmap contains Sprints 00-18 with only objective, major deliverables, and exit gate; it does not present speculative tasks as commitments.

### T-005 Initialize Git and verify Sprint 00

**Acceptance criteria:** Git is initialized without overwriting history; no secrets are staged; the complete Sprint 00 structure is committed with the requested message; all specified checks are reported.
