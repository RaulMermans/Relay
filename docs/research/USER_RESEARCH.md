# User research protocol

Interview 3-5 freelance performance marketers or small-agency practitioners. Collect, with consent and anonymization:

- Raw exports, previous-period exports, and a finished client report
- Reporting cadence and tools used
- Minutes spent cleaning, analyzing, and formatting
- Recurring calculations, attribution/reconciliation issues, and client context
- Most disliked work and report sections clients actually care about

Never commit real client-sensitive material without anonymization.
