# Known issues and limitations

- Browser-local memory is not encrypted, synced, or recoverable after site-data clearing.
- CSV refresh is manual; no background refresh or live OAuth is enabled.
- Browser print/Save-as-PDF layout and destination vary by browser and operating system.
- Private beta is deployment-gated; it is not a public product and has no application accounts.
- Public exposure requires a durable rate/abuse-control design; one is intentionally absent for the controlled beta.
